In this folder you will find a series of 6 tutorials T0 to T5.

These tutorial drive you into the Software Factories course and the application of the concepts learned during each lecture on a realistic case (called SECRET) using the VARIAMOS tool. 

Tutorials should be achieved in sequencial order. 
You can work individually or in group depending on your liking and constraints.

It is highly recommended to test yourself using the corresponding  Multiple Choice Questionnaire after each tutorial and before  starting the following one.
Tests should be done individually as results are recorded in the platform.


As the tests deal both with the tutorial, the lectures and the recommended readings, make sure you have everything in mind before you start them. Be careful : you should have read the corresponding recommended reading before starting any test (or even better, before starting the tutorial)!

Start with tutorial T0 and the corresponding test.
Take your time, there is no rush, but keep in mind that all tutorials should have been achieved before the end of the course (not today's lecture, the overall course)

The final exam will cover all lecture, all tutorials and all recommended readings of the Software Factories course.
