# Décisions d'architecture (ADR)

Une décision qui modifie `docs/01-architecture.md` (nouvelle dépendance, changement de stockage, de transport…) = un fichier `NNN-titre-court.md` :

```
# NNN — Titre
Date : AAAA-MM-JJ · Statut : proposée | acceptée | remplacée par NNN
## Contexte
## Décision
## Conséquences
```
